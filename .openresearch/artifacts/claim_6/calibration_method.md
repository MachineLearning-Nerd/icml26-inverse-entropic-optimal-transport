# Swiss-Roll architecture calibration

Each candidate uses the paper's sample counts, `N`, `M`, learning rates,
25,000 updates, and three fixed seeds. For every paired observation, the
runner creates a fresh minibatch of 64 source and target points, solves the
authors' `rotation-v2` POT Sinkhorn plan, and samples one pair from that plan.

The primary metric is a clean-room sliced `W_2` estimator using 64 fixed,
uniformly spaced projection directions. An independently coded energy
distance is secondary. Conditional targets for the paper's three probe points
are generated by the Appendix D.1 minibatch-64 Sinkhorn procedure. The metric
checker requires exact copies to score zero and a fixed far shift to be
rejected.

Cancelled run `d6134a27-bfa3-4cd2-9032-b73076b2b23b` was rejected after POT
warned that a default-tolerance Sinkhorn solve did not converge. The repaired

stopping tolerance. Every training and evaluation plan is independently
audited; the run is rejected if any maximum row/column marginal residual is
`>=1e-7`.

This is an architecture-selection round, not the final Claim 6 verdict.
Baseline comparisons occur only after the stronger source-faithful candidate
is promoted.
